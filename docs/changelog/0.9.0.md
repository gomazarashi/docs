# バージョン0.9.0（2023年10月31日）

## 参考文献管理
- [CSL](https://citationstyles.org/)（Citation Style Language）に基づく新しい参考文献エンジンを導入しました。一般的に使われる引用スタイルを約100種類同梱し、独自の`.csl`ファイルも読み込めます。
- 異なる形式の引用（文章中への挿入に適した引用など）を生成するための、新しい[`form`]($cite.form)引数を`cite`関数に追加しました。
- [`cite`]($cite)関数は、複数ではなく1つのラベルまたはキーだけを受け取るようになりました。隣接する引用は自動的にまとめられ、引用スタイルの規則に従って書式設定されます。これは、参照構文でも`cite`関数を明示的に呼び出した場合でも動作します。**（破壊的変更）**。
- `cite`関数が、文字列ではなく[ラベル]($label)を受け取るようになりました。**（破壊的変更）**。
- 全ての文献を引用していなくても参考文献全体を表示するための、[`full`]($bibliography.full)引数をbibliography関数に追加しました。
- 参考文献の項目にTypstの数式を含められるようになりました。マークアップと同様に`[$..$]`で囲みます。これは、`.yaml`形式と`.bib`形式の両方で動作します。
- hayagrivaのYAML形式を改善しました。詳細は[変更履歴](https://github.com/typst/hayagriva/blob/main/CHANGELOG.md)をご覧ください。**（破壊的変更）**。
- `.bib`ファイルのパースに関するバグをいくつか修正しました。
- `cite`関数の`brackets`引数を削除し、`form`へ置き換えました。

## 視覚化
- グラデーションと色（[@Dherse](https://github.com/Dherse)に感謝します）
  - 図形と文章の[グラデーション]($gradient)に対応しました。
  - 線形、放射状、円錐状のグラデーションに対応しました。
  - [Oklab]($color.oklab)、[Linear RGB(A)]($color.linear-rgb)、[HSL]($color.hsl)、[HSV]($color.hsv)など、より多くの色空間での色の定義に対応しました。
  - 色の[`saturate`]($color.saturate)、[`desaturate`]($color.desaturate)、[`rotate`]($color.rotate)関数を追加しました。
  - グラデーションで使用できる定義済みのカラーマップを持つ、[`color.map`]($color/#predefined-color-maps)モジュールを追加しました。
  - 色の`kind`関数の名前を[`space`]($color.space)へ変更しました。
  - `to-rgba`、`to-cmyk`、`to-luma`関数を削除し、新しい[`components`]($color.components)関数へ置き換えました。
- 角丸でストロークの太さが辺ごとに異なる[長方形]($rect)のレンダリングを改善しました。
- 角丸の[ボックス]($box.clip)と[ブロック]($block.clip)を正しくクリッピングできるようになりました。
- [`overline`]($overline)、[`underline`]($underline)、[`strike`]($strike)関数に`background`パラメーターを追加しました。
- PDFへの色の埋め込みが不正確な問題を修正しました。
- PDFへ埋め込んだ画像のICCプロファイルの処理を修正しました。

## 文章とレイアウト
- CJKの文章とラテン文字の文章の間で、適切な[間隔]($text.cjk-latin-spacing)を自動的に追加する機能に対応しました。デフォルトで有効です。
- より多くのCJKの句読点の自動調整に対応しました。
- 出典を任意で指定して、インライン引用やブロック引用を挿入する[`quote`]($quote)要素を追加しました。
- rawテキストの各行の表示をカスタマイズする[`raw.line`]($raw.line)要素を追加しました。例えば、適切なシンタックスハイライトを維持しながら行番号を追加できます。
- table関数で、辺ごとの[内側の余白]($table.inset)のカスタマイズに対応しました。
- ハンガリー語とルーマニア語の翻訳を追加しました。
- チェコ語のハイフネーションに対応しました。
- 独自の[スマートクォート]($smartquote)の設定に対応しました。
- デフォルトの[図表の区切り文字]($figure.caption.separator)が、現在設定されている言語と地域を反映するようになりました。
- リンクやURLの改行処理を改善しました。特に、多くのURLを含む参考文献で役立ちます。
- 均等割り付けのアルゴリズムで、連続するハイフンの処理を改善しました。
- 均等割り付けとぶら下げインデントの組み合わせを修正しました。
- 均等割り付けが有効な場合に、空白を含まない短い行の改行処理のバグを修正しました。
- ハイフネーションで生成されたハイフンのフォントフォールバックを修正しました。
- ハイフネーション時のワードジョイナーやその他の改行禁止文字の処理を修正しました。
- 空行の後でハイフネーションする際のクラッシュを修正しました。
- 🏳️‍🌈のような複合絵文字の改行処理を修正しました。
- 一部のSVGでテキストが欠落する問題を修正しました。
- SVG内のフォントフォールバックを修正しました。
- `pagebreak`関数の[`to`]($pagebreak.to)引数の動作を修正しました。
- 数式に対する`{set align(..)}`を修正しました。
- [配置した]($place)要素の前後の間隔を修正しました。
- [`above`]($block.above)と[`below`]($block.below)の間隔をem単位で指定し、フォントサイズが異なる場合の間隔の統合を修正しました。
- [`underline`]($underline)、[`overline`]($overline)、[`strike`]($strike)関数の`extent`パラメーターの処理を修正しました。
- 垂直方向の配置を指定していない[フロート配置した要素]($place.float)でのクラッシュを修正しました。
- 脚注内の引用のバグを部分的に修正しました。

## 数式
- [`vec`]($math.vec.gap)、[`mat`]($math.mat.gap)、[`cases`]($math.cases.gap)関数に`gap`引数を追加しました。
- [`abs`]($math.abs)、[`norm`]($math.norm)、[`floor`]($math.floor)、[`ceil`]($math.ceil)、[`round`]($math.round)関数に`size`引数を追加しました。
- cases関数に[`reverse`]($math.cases.reverse)パラメーターを追加しました。
- [`binom`]($math.binom)関数で、多項係数に対応しました。
- [`cancel`]($math.cancel)関数の`rotation`引数を削除し、より柔軟な新しい`angle`引数へ置き換えました。**（破壊的変更）**。
- `quad`の2倍の間隔を挿入する`wide`定数を追加しました。
- `csch`[演算子]($math.op)と`sech`演算子を追加しました。
- `↼`、`⇀`、`↔`、`⟷`を[アクセント]($math.accent)として使用できるようになりました。
- `integral.dash`、`integral.dash.double`、`integral.slash`の[記号]($category/symbols/sym)を追加しました。
- 行列の[補助線]($math.mat.augment)で、後ろから位置を指定するための負のインデックスに対応しました。
- 行列の[補助線]($math.mat.augment)のデフォルトの色を修正しました。
- インライン式へのプライムの付け方を修正しました。
- 数式コンテンツが、文章の[ベースライン]($text.baseline)設定を反映するようになりました。

## パフォーマンス
- テンプレートのshowルールに関するバグを修正しました。このバグは、影響を受ける文書でインクリメンタルコンパイルを実質的に無効にしていました。
- 頻繁に実行される複数の処理のコードを細かく最適化しました。特にインクリメンタルコンパイルのパフォーマンスが大きく向上します。
- インクリメンタルパースを改善しました。これはインクリメンタルコンパイルの処理全体へ影響します。
- CLIでインクリメンタルパースに対応しました。
- PDFエクスポートでSVGのインクリメンタルエンコードに対応しました。多くのSVGを含む文書のエクスポートのパフォーマンスが大きく向上します。

## ツールと診断
- スコープ内の変数の自動補完を改善しました。
- パッケージのインポートの自動補完を追加しました。
- [ラベル]($label)の自動補完を追加しました。
- 関数の等号や矢印にカーソルを合わせると、その関数が取り込む変数を表示するツールチップを追加しました。
- 診断の重複を排除するようになりました。
- 二項演算の`+`と`-`だけに対応する型へ、単項演算の`+`や`-`を適用しようとした場合の診断を改善しました。
- 文書や参考文献に存在しないラベルや引用キーを、エラーメッセージへ明示するようになりました。
- 関数の引数のパースエラーが、関数の実行エラーに隠されるバグを修正しました。例えば、[`array.sorted`]($array.sorted)を呼び出す際、キー関数を名前付き引数ではなく位置引数で渡した場合に起きていました。

## エクスポート
- 文書の作成日時（[`date`]($document.date)）の設定に対応しました。`date`がデフォルトの`{auto}`の場合、PDFの作成日時は現在の日時になります。
- 文書のキーワード（[`keywords`]($document.keywords)）の設定に対応しました。
- 生成したPDFに、PDF文書IDを含めるようになりました。
- PDFの作成ツールのメタデータに、Typstのバージョンを含めるようになりました。

## Webアプリ
- プロジェクトを古いコンパイラーバージョンへ固定する、バージョン選択機能を追加しました。Typst 0.6.0以降に対応しています。
- エディターとコンパイラーの同期のずれを修正し、全体的な安定性を改善しました。
- 文書のコンパイル中に入力しても、文書のハイライトを継続するようになりました。

## コマンドラインインターフェース
- fontconfigによるフォントの検出に対応しました。
- 端末のリセットではなく、画面を消去するようになりました。
- 選択した出力形式に適したファイル拡張子を、自動的に選ぶようになりました。
- PNGやSVGエクスポートで`typst watch`を使用する場合、変更されたページの画像だけを再生成するようになりました。

## その他の改善
- [`version`]($version)型と、現在のコンパイラーバージョンを示す`sys.version`定数を追加しました。複数のバージョンへ無理なく対応するために使用できます。
- 数値の表示、全ての数値の[`repr`]($repr)、文章モードで数字の前にある通常のハイフンの置換に、U+2212 MINUS SIGNを使用するようになりました。特に、数式モードでの負の整数の表示が改善されます。
- [配列]($array.remove)と[辞書]($dictionary.remove)の`remove`関数で、失敗する代わりにデフォルト値を指定できるようになりました。
- ページ設定ガイドの例を簡略化しました。
- ドキュメントで、適切な箇所の「ハッシュタグ」という語を「ハッシュ」へ変更しました。
- 追加の引数なしでの[`array.zip`]($array.zip)に対応しました。
- プラグインが範囲外のメモリーを読み込もうとした場合のクラッシュを修正しました。
- 無限の[長さ]($length)を処理する場合のクラッシュを修正しました。
- 文書の末尾付近の弱い改ページによる内省のバグ（主に参考文献）を修正しました。

## 開発
- `typst::ide`を独立した`typst_ide`クレートへ分離しました。
- `&dyn World`に残っていた`'static`境界をいくつか削除しました。
- 不要な依存関係を削除し、バイナリーサイズを削減しました。
- `typst`単体（`typst-library`なし）でのコンパイルを修正しました。
- `lib.getExe`を使用する場合のNix flakeの警告を修正しました。
