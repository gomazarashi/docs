# バージョン0.6.0（2023年6月30日）

## パッケージ管理
- Typstに[パッケージ管理]($scripting/#packages)が組み込まれました。
- コミュニティーが[公開した]($universe)パッケージをインポートしたり、[システム内のローカルパッケージ](https://github.com/typst/packages#local-packages)を作成して使用したりできます。
- 公開パッケージはWebアプリでも利用できます。

## 数式
- 数式モードで、グリフのオプティカルサイズのバリアントに対応しました。
- 数式が[`display`]($math.display)スタイルか[`inline`]($math.inline)スタイルかに応じて、[`limits`]($math.limits)を条件付きで有効にする引数を追加しました。
- `gt.eq.slant`記号と`lt.eq.slant`記号を追加しました。
- 数式モードでの階乗の優先順位を上げました。`[$1/n!$]`が正しく動作するようになりました。
- 数式モードの[下線]($math.underline)と[上線]($math.overline)を改善しました。
- showルール内での[`limits`]($math.limits)関数の使用を修正しました。
- 数式内の改行に関するバグを修正しました。

## 文章とレイアウト
- `inside`キーと`outside`キーで、左右交互のページの[余白]($page.margin)を設定できるようになりました。
- ページの[`binding`]($page.binding)の指定に対応しました。
- 次の偶数ページまたは奇数ページへ進むための[`to`]($pagebreak.to)引数をpagebreak関数に追加しました。
- さらにいくつかの言語（TR、SQ、TL）の基本的な国際化対応を追加しました。
- 改ページで表の行が欠落するバグを修正しました。
- [下線]($underline)のバグを修正しました。
- 表に余分な線が表示されるバグを修正しました。
- 改行後のスマートクォートを修正しました。
- 文章のレイアウトに関するクラッシュを修正しました。

## コマンドラインインターフェース
- **破壊的変更**：`--root`/`TYPST_ROOT`ディレクトリーは、入力ファイルを含む必要があるようになりました。これは、このディレクトリーが_プロジェクト_のルートを示すためです。`TYPST_ROOT`でパッケージ管理を模倣している既存の設定では、[ローカルパッケージ](https://github.com/typst/packages#local-packages)へ移行してください。
- **破壊的変更**：プロジェクトルートの外にあるファイルへのアクセスを拒否するようになりました。
- ローカルパッケージと、必要に応じたパッケージのダウンロードに対応しました。
- プロジェクトルートと全てのパッケージ内の、関連する全ファイルを監視するようになりました。
- コンパイル時間を表示するようになりました。

## その他の改善
- showルールでアウトラインの項目をカスタマイズする[`outline.entry`]($outline.entry)を追加しました。
- エラーメッセージのヒントをいくつか追加しました。
- [`raw`]($raw)のシンタックスハイライトで、未対応だった構文をいくつか追加しました。
- PNGエクスポートとWebアプリで、回転した画像のレンダリングを改善しました。
- [脚注]($footnote)を再利用、参照できるようにしました。
- [`locate`]($locate)内の引用と参考文献のバグを修正しました。
- ドキュメント内の時制の不一致を修正しました。

## 開発
- [貢献ガイド](https://github.com/typst/typst/blob/main/CONTRIBUTING.md)を追加しました。
- パッケージ管理への対応と実装の簡素化のため、`World`インターフェースを作り直しました_（実装者にとっての破壊的変更）_。
