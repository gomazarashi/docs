# バージョン0.12.0（2024年10月18日）

## 主な変更点
- 複数の段をまたぐ[フロート配置]($place.scope)と[図表]($figure.scope)に対応しました。
- 学術論文などで使われる、自動的な[行番号付け]($par.line)に対応しました。
- Typstのレイアウトエンジンをマルチスレッド化しました。大きな文書では、通常2～3倍高速化します。マルチスレッド処理は改ページの境界で動作するため、有効にするには明示的な改ページが必要です。
- 新しい2パスのアルゴリズムで、段落の均等割り付けを最適化しました。短い段落ほど効果が大きく、最大6倍高速化します。
- フォントのサブセット化の改善により、PDFのファイルサイズを大幅に削減しました（[@LaurenzV](https://github.com/LaurenzV)に感謝します）。
- PDFへ絵文字を正しくエクスポートするようになりました。
- PDF/Aへの初期対応を追加しました。現時点ではPDF/A-2bプロファイルのみ対応していますが、今後さらに追加する予定です。
- CLIの環境（フォント、パッケージのパスなど）を設定する、さまざまなオプションを追加しました。
- 文章のshowルールが、複数の文章要素をまたいで一致するようになりました。
- ブロックレベルの数式を、任意で複数ページへ分割できるようになりました。
- 一部のフォントが業務用プリンターで正しく印刷されないバグを修正しました。
- 見出しがページ下部へ取り残されることがある、長年のバグを修正しました。

## レイアウト
- [`place.scope`]($place.scope)と[`figure.scope`]($figure.scope)で、複数の段をまたぐフロート配置と図表に対応しました。2段組みの文書では、`{show: column.with(2)}`よりも`{set page(columns: 2)}`を優先してください（[ページ設定ガイド]($guides/page-setup/#columns)を参照）。
- 学術論文などで使われる、自動的な[行番号付け]($par.line)に対応しました。
- 段落間の間隔を設定する[`par.spacing`]($par.spacing)プロパティーを追加しました。今後は、`{show par: set block(spacing: ..)}`の代わりにこちらを使用してください。**（破壊的変更）**。
- リスト、グリッド、スタックなどのブロックレベルの要素が、自身をブロックとして表示するようになりました。そのため、`spacing`だけでなく、`stroke`など全てのブロックのプロパティーの影響を受けます。**（破壊的変更）**。
- ブロックの後の改ページを防ぐ、[`block.sticky`]($block.sticky)プロパティーを追加しました。
- 後続のコンテンツより前に、全てのフロート図表を強制的に配置する[`place.flush`]($place.flush)関数を追加しました。
- [`skew`]($skew)関数を追加しました。
- [`page.header`]($page.header)と[`page.footer`]($page.footer)に、番号付けに基づいてヘッダーとフッターを自動生成する`{auto}`オプションを追加しました。以前は、一度変更するとこの自動生成を利用できませんでした。
- [`repeat`]($repeat)関数に`gap`パラメーターと`justify`パラメーターを追加しました。
- コンテンツを計測する空間を定義する`width`パラメーターと`height`パラメーターを、[`measure`]($measure)関数に追加しました。特に、[`layout`]($layout)との組み合わせで役立ちます。
- `block`、`image`、`rect`、`square`、`ellipse`、`circle`の高さを、[比率の単位]($fraction)で指定できるようになりました。
- [`scale`]($scale)関数の`x`、`y`、`factor`が、絶対長に対応しました。これにより、サイズが不明な要素を固定のサイズへ拡大・縮小できます。
- コンテキスト式で、`block.above`と`block.below`の値を取得できるようになりました。
- 絶対単位（pt、mm、cm、in）の間の変換精度を高めました。
- 見出しがページ下部へ取り残されることがあるバグを修正しました。
- 分割可能なブロック内の脚注が、脚注マーカーのあるページではなく、そのブロックが終わるページに表示される問題を修正しました。
- 入れ子の脚注とフロート内の脚注の番号付けを修正しました。
- [コンテキスト]($context)式でページ全体を囲むと、空のページが現れる問題を修正しました。
- `{set block(spacing: x)}`が`{set block(above: x, below: x)}`と異なる動作をする問題を修正しました。
- `{reflow: true}`の場合の、[`rotate`]($rotate)と[`scale`]($scale)の動作を修正しました。
- `{align(horizon)}`と`{v(1fr)}`の組み合わせを修正しました。
- フロート配置の結果が重なってしまう、さまざまなバグを修正しました。
- ウィドウ・オーファンの防止処理が、不必要に文章を次の段へ移動するバグを修正しました。
- [弱い間隔]($h.weak)が、段落の先頭と末尾だけでなく、段落内の各行の先頭と末尾でも削除されるよう修正しました。
- 弱い改ページと[`pagebreak.to`]($pagebreak.to)の組み合わせを修正しました。
- 単独の弱い改ページのコンパイル出力を修正しました。
- `{100%}`の[余白]($pad)を設定した場合のクラッシュを修正しました。

## 文章
- ハイフネーションを調整しました。デフォルトでハイフネーションを控えめにし、特に単語の端に近い位置でのハイフネーションを避けるようになりました。**（レイアウトが大きく変わることもあります）**。
- 新しいデフォルトフォントをLibertinus Serifにしました。これは、以前のデフォルトフォントであるLinux Libertineの、保守が続いている後継です。**（レイアウトが少し変わることもあります）**。
- 利用できないフォントファミリーを指定すると、警告を出すようになりました。
- 新しいスマートクォートのアルゴリズムを実装し、スマートクォートが適切に動作しないさまざまなバグを修正しました。
- 文章のレイアウト時にレイアウトエンジンの選択へ影響する、さまざまなパラメーターを調整するための[`text.costs`]($text.costs)パラメーターを追加しました。
- [rawブロック]($raw.lang)で、数式向けの`typm`ハイライトモードを追加しました。
- ガリシア語、カタルーニャ語、ラテン語、アイスランド語、ヘブライ語の基本的な国際化対応を追加しました。
- チェコ語、クロアチア語、低地ソルブ語、ポーランド語、ポルトガル語、スロバキア語、スペイン語でのハイフンの繰り返しを実装しました。
- [`smallcaps`]($smallcaps)関数が要素関数となり、showルールやshow-setルールで使用できるようになりました。
- [`raw.theme`]($raw.theme)パラメーターを`{none}`に設定すると、言語タグがあってもハイライトを無効にできます。また、`{auto}`でデフォルトへ戻せます。
- 複数の[スタイリスティックセット]($text.stylistic-set)を同時に有効化できるようになりました。
- 「Equation」の中国語訳を修正しました。
- 単語の外でハイフネーションが起こる問題を修正しました。
- 特定の条件での双方向テキストのレイアウトの誤りを修正しました。
- 末尾に明示的な空白を持つ段落のレイアウトを修正しました。
- `#""`によって作られる空の段落のバグを修正しました。
- インライン数式の直前の改行で、意図しない末尾の空白が入る問題を修正しました。
- [`text.historical-ligatures`]($text.historical-ligatures)が正しく動作しない問題を修正しました。
- 特定の状況で、改行の前後にタイ語の文字が意図せず繰り返される問題を修正しました。
- スイスのフランス語の[スマートクォート]($smartquote)を修正しました。
- Archivo、Kaiti SC、Kaiti TC向けのフォントメタデータの例外処理を追加しました。
- 同梱のNew Computer Modernフォントをバージョン6.0へ更新しました。

## 数式
- `{show math.equation: set block(breakable: true)}`で有効化すると、ブロックレベルの数式を複数ページへ分割できるようになりました。
- セルの内容が異なる場合も、行列とベクトルのサイズ決定の一貫性を高めました。
- 矢印や括弧などの文字を、手動または自動で水平・垂直方向へ伸縮させる[`stretch`]($math.stretch)関数を追加しました。
- 括弧で囲まれた式や、下線・上線を持つ式のアタッチメントのレイアウトを改善しました。
- `[#let a0 = $a_0$; $a0^1$]`のようなコードで生じる、入れ子のアタッチメントのレイアウトを改善しました。
- 上付き文字に近いプライムのレイアウトを改善しました。
- 分数のレイアウトを改善しました。
- 一部のフォントにある数式専用の、高さに依存するカーニング情報を使用して、アタッチメントのレイアウトを改善するようになりました。
- 数式の`floor`関数と`ceil`関数が、呼び出し可能な記号になりました。これにより、`[$ floor(x) = lr(floor.l x floor.r) $]`と書けます。
- [`mat.delim`]($math.mat.delim)、[`vec.delim`]($math.vec.delim)、[`cases.delim`]($math.cases.delim)パラメーターに、Unicodeで区切り記号や「フェンス」とされる任意の文字（|など）を指定できるようになりました。`{delim: "||"}`表記は*非対応*となったため、`{delim: bar.double}`へ置き換えてください。**（軽微な破壊的変更）**。
- [`vec.align`]($math.vec.align)パラメーターと[`mat.align`]($math.mat.align)パラメーターを追加しました。
- [`underparen`]($math.underparen)、[`overparen`]($math.overparen)、[`undershell`]($math.undershell)、[`overshell`]($math.overshell)を追加しました。
- 数式モードで、`tilde.op`の短縮記法として`~`を追加しました。**（軽微な破壊的変更）**。
- 数式番号のベースラインの配置を修正しました。
- 角括弧（⌜、⌝、⌞、⌟）の位置を修正しました。
- 大きな根号のベースラインを修正しました。
- アタッチメントの小さなレイアウトのバグを複数修正しました。
- 配置ポイントが数式の行の高さへ影響する問題を修正しました。
- 数式内の文章と、[`metadata`]($metadata)のような不可視の要素の間に、空白が現れる問題を修正しました。
- 数式内の再帰的なshowルールでのクラッシュを修正しました。
- 場合によって[`lr.size`]($math.lr.size)が[`mid`]($math.mid)で囲まれた文字へ影響しない問題を修正しました。
- 下付き文字と上付き文字でのem単位の解決を修正しました。
- [文章の端]($text.top-edge)を`{"bounds"}`に設定した場合の、インライン数式のバウンディングボックスを修正しました。

## 内省
- 要素がページ上のどこへ配置されるかを追跡する、新しい仕組みを実装しました。これにより、内省の動作が微妙に変わる可能性があります。**（破壊的変更）**。
- より原則に沿った新しい実装によって、複雑なレイアウトでのカウンターの動作が誤る、さまざまなバグを修正しました。
- 弱い改ページで分離すると、カウンターを最初のページの前、ページの間、最後のページの後でも更新できるようになりました。例えば、最初のページのヘッダーや背景より前にカウンターを更新できます。
- 脚注と図表内での内省の論理的な順序を修正しました。
- コンテキスト式内で[`place`]($place)を使用した場合の、誤った[`here().position()`]($here)を修正しました。
- showルールが改ページの前に不可視の要素（状態の更新など）を出力する場合、要素（特に見出し）の解決後の位置が誤る問題を修正しました。
- カウンターの現在の状態より深いレベルで、カウンターを進める動作を修正しました。
- 表のヘッダーなどの一部の場所で、引用の書式設定が動作しない問題を修正しました。
- 脚注カウンターの表示が、脚注の番号付けのスタイルを反映するようになりました。

## モデル
- documentのsetルールを、文書の最初に置く必要がなくなりました。レイアウトのコンテナー内へ置けないことが、唯一の制限です。
- [箇条書きリスト]($list.spacing)、[番号付きリスト]($enum.spacing)、[用語リスト]($terms.spacing)の`spacing`プロパティーを、詰めたリストでも反映するようになりました。
- 詰めたリストは、任意のブロックではなく、直前の段落だけに詰めた間隔で続くようになりました。
- [`quote`]($quote)要素がロケータブルになり、検索で使用できるようになりました。
- 参考文献の見出しが`level`ではなく`depth`を使用するようになり、show-setルールで引き続きレベルを設定できます。
- デーヴァナーガリー、東アラビア数字、ベンガル数字、丸数字など、より多くの[番号付け]($numbering)形式に対応しました。
- 複数行の見出しの外観を調整する[`hanging-indent`]($heading.hanging-indent)パラメーターをheading関数に追加し、デフォルトの外観も改善しました。
- アウトラインの項目での双方向テキストの処理を改善しました。
- 他の内容がない文書で、documentのsetルールが無視される問題を修正しました。
- コンテキスト式でdocumentのsetルールを使用できない問題を修正しました。
- `{set document}`と`{set page}`の組み合わせの問題を修正しました。
- `{show figure: set align(..)}`を修正しました。デフォルトの図表の配置をshow-setルールとしたため、`{show figure: it => it.body}`で取り消されなくなりました。**（軽微な破壊的変更）**。
- 脚注への参照の番号付けを修正しました。
- 参考文献の見出しの後の間隔を修正しました。

- 参考文献の項目のソートを修正しました。
- ページ範囲のラベルの複数形への変化を修正しました。
- 引用番号による引用のソートを修正しました。
- 引用番号の範囲のまとめ方を修正しました。

## エクスポート
- フォントのサブセット化の改善により、PDFのファイルサイズを大幅に削減しました。
- PDFへ絵文字を正しくエクスポートするようになりました。
- PDF/Aへの初期対応を追加しました。現時点ではPDF/A-2b規格のみ対応していますが、今後さらに追加する予定です。CLIでは`--pdf-standard
  a-2b`、Webアプリでは「ファイル」→「エクスポート」→「PDF」のUIから有効化できます。
- [`page.fill`]($page.fill)を`{none}`に設定すると、PNGとSVGのページは白ではなく透明になります。新しいデフォルトの`{auto}`は、PDFでは透明、PNGとSVGでは白を意味します。
- 複雑な状況での、PDFからの文章のコピー＆ペーストを改善しました。
- エクスポートしたSVGで、ラベル付きの[ボックス]($box)と[ブロック]($block)から生成したグループに、`data-typst-label`属性を含めるようになりました。
- 一部のフォントが業務用プリンターで正しく印刷されないバグを修正しました。
- あるPDFオブジェクトの透明度が、別のオブジェクトへ漏れることがあるバグを修正しました。
- PDFのCMYKグラデーションのバグを修正しました。
- PDFでのOklabグラデーションのエクスポートの、さまざまなバグを修正しました。
- アウトライン形式でないグリフのレンダリングに関するクラッシュを修正しました。
- PDF規格への準拠に関する小さな修正を2つ行いました。

## パフォーマンス
- Typstのレイアウトエンジンをマルチスレッド化しました。大きな文書では、通常2～3倍高速化します。マルチスレッド処理は改ページの境界で動作するため、有効にするには明示的な改ページが必要です。
- 新しい2パスのアルゴリズムで、段落の均等割り付けを最適化しました。短い段落ほど効果が大きく、1～6倍高速化します。

## コマンドラインインターフェース
- エクスポートするページ範囲を選ぶ`--pages`オプションを追加しました。
- パッケージの読み込み先とキャッシュ先をそれぞれ設定する、`--package-path`と`--package-cache-path`、および環境変数`TYPST_PACKAGE_PATH`と`TYPST_PACKAGE_CACHE_PATH`を追加しました。
- 再現性を高めるため、システムフォントを完全に無効化する`--ignore-system-fonts`フラグを追加しました。
- 現在のコンパイルの依存関係をMakefileとして出力する`--make-deps`引数を追加しました。
- `typst query`に`--pretty`オプションを追加し、デフォルトでは出力を圧縮するようになりました。これはJSON形式にのみ適用されます。
- 以前のバージョンのバックアップ先を設定する`--backup-path`を、`typst update`に追加しました。
- ヘルプ出力に役立つリンクを追加しました。
- CLIで初めて`typst`だけを実行したユーザーへ、案内を表示するようになりました。
- 出力ファイル名として`-`を渡すと、文書を標準出力へ書き出せるようになりました。PDFまたは単一ページの画像のエクスポートに対応しています。
- `--cert`や`TYPST_CERT`で指定した証明書を読み込めない場合、何も表示せず失敗する代わりに、適切なエラーメッセージを出すようになりました。
- 再現性を高めるため、`SOURCE_DATE_EPOCH`環境変数を反映するようになりました。
- 複数の画像をエクスポートする場合、出力パスで`{t}`（総ページ数）、`{p}`（現在のページ）、`{0p}`（ゼロ埋めした現在のページ。従来の`{n}`と同じ）を使用できるようになりました。
- 入出力パスで、UTF-8でない値を使用できるようになりました。
- CLI全体で、時間の書式の一貫性を高めました。
- `--open`フラグに関するバグを修正しました。
- zshで`typst`のパス補完が動作しない問題を修正しました。

## ツールと診断
- パッケージが必要とするTypstの最低バージョンを指定する「compiler」フィールドで、0.11.0ではなく0.11のような、大まかなバージョン指定に対応しました。
- 直前にラベルを付けられる要素がなく、Typstがラベルを無視する場合の警告を追加しました。
- コードモードでラベルを適用しようとした場合のヒントを追加しました。
- ローカルの定義で隠蔽・上書きされた標準ライブラリー関数を、呼び出そうとした場合のヒントを追加しました。
- `lang`パラメーターに、言語と地域の両方を設定しようとした場合のヒントを追加しました。
- 誤って`typst c file.pdf`と入力した場合など、Typst以外のファイルをコンパイルしようとした場合のヒントを追加しました。
- ラベルが必要な箇所で文字列を使用した場合のヒントを追加しました。
- 対応する開始記号のないブロックコメントの終端（`*/`）に遭遇した場合のヒントを追加しました。
- 要素数が異なる配列を分割しようとした場合のヒントを追加しました。
- letバインディングでキーワードを識別子として使用しようとした場合の、エラーメッセージを改善しました。
- 存在しないフィールドへアクセスした場合のエラーメッセージを改善しました。
- パッケージは存在するものの、指定したバージョンが存在しない場合のエラーメッセージを改善しました。
- 不明な変数へのヒントを改善しました。
- ゼロでないem成分を持つ長さを絶対単位へ変換しようとした場合の、ヒントを改善しました。
- 特定のホバー時のツールチップで起こりうるクラッシュを修正しました。
- first-line-indentが有効な場合の、ソースへのジャンプのオフバイワンエラーを修正しました。
- インラインのコード式の末尾の後の、`.`に対する提案を修正しました。
- 特定のケースで自動補完が重複する問題を修正しました。

## 開発
- `World`の実装者に役立つAPIを提供する、`typst-kit`クレートを追加しました。
- `typst-ide`に定義へのジャンプのAPIを追加しました。
- `typst-syntax`にパッケージマニフェストのパースのAPIを追加しました。
- コンパイラーがマルチスレッドに対応したため、`World`実装は`Send`と`Sync`を満たす必要があります。
- メインファイルを読み込めない状況に対応できるよう、`World::main`のシグネチャーを変更しました。
- `Tracer`を削除し、`Warned<T>`と`typst::trace`関数へ置き換えました。
- 自己更新で使用する`xz2`依存関係を、静的にリンクするようになりました。
- Dockerfileに`ENTRYPOINT`命令を追加しました。
