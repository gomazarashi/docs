# バージョン0.7.0（2023年8月7日）

## 文章とレイアウト
- figure関数の[`placement`]($figure.placement)引数で、図表のフロート配置に対応しました。
- place関数の[`float`]($place.float)引数で、任意のコンテンツのフロート配置に対応しました。
- rawブロックのシンタックスハイライト用の[構文]($raw.syntaxes)として、`.sublime-syntax`ファイルを読み込めるようになりました。
- rawブロックのシンタックスハイライト用の[テーマ]($raw.theme)として、`.tmTheme`ファイルを読み込めるようになりました。
- text関数の[`top-edge`]($text.top-edge)引数と[`bottom-edge`]($text.bottom-edge)引数に、ぴったりとしたバウンディングボックスを得るための*bounds*オプションを追加しました。
- 下端に対する*ascender*など、意味をなさない上端・下端のオプションを削除しました。**（破壊的変更）**。
- text関数に[`script`]($text.script)引数を追加しました。
- スマートクォート関数に[`alternative`]($smartquote.alternative)引数を追加しました。
- 日本語の基本的な国際化対応を追加しました。
- `no`に加えて、言語コード`nb`と`nn`のハイフネーションに対応しました。
- コンテナー内の[配置した要素]($place)の位置を修正しました。
- 改行の最適化によってコンテナーからはみ出す問題を修正しました。

## エクスポート
- SVG画像のPDFへのエクスポートを大幅に改善しました。この作業を手がけた[@LaurenzV](https://github.com/LaurenzV)に感謝します。
- PDFエクスポートで、RGBAカラーのアルファチャンネルに対応しました。
- PNGエクスポートでのPPI（1インチあたりのピクセル数）のバグを修正しました。

## 数式
- プライムのレイアウト（`[$a'_1$]`など）を改善しました。
- 複数のプライムの表示（`[$a''$]`など）を改善しました。
- [根号]($math.root)のレイアウトを改善しました。
- 関係記号のアタッチメントを、デフォルトで[limits]($math.limits)として表示するよう変更しました（`[$a ->^x b$]`など）。
- 大型演算子と区切り記号は、常に垂直方向の中央へ配置するようになりました。
- 数式内の[ボックス]($box)は、デフォルトで垂直方向の中央ではなくベースラインへ配置するようになりました。[ブロック]($block)はインライン要素ではないため、この変更の影響を受けません。
- [弱い間隔]($h.weak)に対応しました。
- OpenTypeの文字バリアントに対応しました。
- コンテンツの[数式クラス]($math.class)のカスタマイズに対応しました。
- `.`、`\/`、`...`の前後の間隔を修正しました。
- 閉じ区切り記号と大型演算子の間隔を修正しました。
- 数式フォントのウェイト選択のバグを修正しました。
- 記号と演算子 **（破壊的変更）**。
  - テキスト[演算子]($math.op)の`id`、`im`、`tr`を追加しました。
  - `ident`の名前を`equiv`へ変更し、別名`eq.triple`を追加しました。また、`ident.strict`を削除して`eq.quad`へ置き換えました。
  - `ast.sq`の名前を`ast.square`へ、`integral.sq`の名前を`integral.square`へ変更しました。
  - `tilde`、`gt`、`lt`、`prec`、`succ`の修飾子`.eqq`を`.equiv`へ、`.neqq`を`.nequiv`へ変更しました。
  - `nothing`の別名として`emptyset`を追加しました。
  - `prec`と`succ`の別名として、`lt.curly`と`gt.curly`を追加しました。
  - `alef`、`bet`、`gimel`の別名として、`aleph`、`beth`、`gimmel`を追加しました。

## スクリプト記述
- フィールド
  - [長さ]($length)に`abs`フィールドと`em`フィールドを追加しました。
  - [相対的な長さ]($relative)に`ratio`フィールドと`length`フィールドを追加しました。
  - [2次元の配置]($align.alignment)に`x`フィールドと`y`フィールドを追加しました。
  - [ストローク]($stroke)に`paint`、`thickness`、`cap`、`join`、`dash`、`miter-limit`フィールドを追加しました。
- アクセサーとユーティリティーメソッド
  - 配列に[`dedup`]($array.dedup)メソッドを追加しました。
  - [長さ]($length)に`pt`、`mm`、`cm`、`inches`メソッドを追加しました。
  - [角度]($angle)に`deg`メソッドと`rad`メソッドを追加しました。
  - [色]($color)に`kind`、`hex`、`rgba`、`cmyk`、`luma`メソッドを追加しました。
  - [方向]($stack.dir)に`axis`、`start`、`end`、`inv`メソッドを追加しました。
  - [配置]($align.alignment)に`axis`メソッドと`inv`メソッドを追加しました。
  - [2次元の配置]($align.alignment)に`inv`メソッドを追加しました。
  - 配列の[`enumerate`]($array.enumerate)メソッドに`start`引数を追加しました。
- [`color.mix`]($color.mix)関数を追加しました。
- [`eval`]($eval)関数に`mode`引数と`scope`引数を追加しました。
- 大きなバイトバッファーを保持する[`bytes`]($bytes)型を追加しました。
  - ファイルを文字列ではなくバイト列として読み込むための[`encoding`]($read.encoding)引数をread関数に追加しました。
  - 文字列やバイト列から画像を直接デコードする[`image.decode`]($image.decode)関数を追加しました。
  - 文字列や整数の配列をバイト列へ変換する[`bytes`]($bytes)関数を追加しました。
  - バイト列を整数の配列へ変換する[`array`]($array)関数を追加しました。
  - [`str`]($str)関数で、バイト列から文字列への変換に対応しました。

## ツールと診断
- コンパイラーの警告に対応しました。
- 内省機能の多用によって、5回の試行でもコンパイルが収束しない場合の警告を追加しました。
- 空の強調（`__`と`**`）に対する警告を追加しました。
- 無効なフィールド代入のエラーメッセージを改善しました。
- 単独の`#`の後のエラーメッセージを改善しました。
- 識別子が必要な箇所でキーワードを使用した場合のエラーメッセージを改善しました。
- モジュール内の関数のパラメーターの自動補完を修正しました。
- インポートの自動補完では、コロンを入力するまで最新のパッケージバージョンだけを表示するようになりました。
- 空白を含む辞書のキーの自動補完を修正しました。
- `for`ループの自動補完を修正しました。

## コマンドラインインターフェース
- コマンドラインで[検索]($reference/introspection/query/#コマンドラインクエリ)するための`typst query`サブコマンドを追加しました。
- `--root`引数と`--font-paths`引数を、コマンドの前に指定できなくなりました。**（破壊的変更）**。
- ローカルパッケージとキャッシュ済みパッケージを、`[{namespace}/{name}-{version}]`ではなく`[{namespace}/{name}/{version}]`形式のディレクトリーへ保存するようになりました。**（破壊的変更）**。
- 明示的に指定したフォント（`--font-paths`経由）とシステムフォントや埋め込みフォントの両方が存在する場合、明示したフォントを優先するようになりました。
- 一部のテキストエディターで`typst watch`が動作しない問題を修正しました。
- 表示されるコンパイル時間を修正し、エクスポートの時間も含むようになりました。

## その他の改善
- 見出しをPDFアウトラインへ含めるかどうかを制御する[`bookmarked`]($heading.bookmarked)引数をheadingに追加しました。
- 図表のキャプションの位置を制御する[`caption-pos`]($figure.caption.position)引数を追加しました。
- 任意の値を内省システムへ公開する[`metadata`]($metadata)関数を追加しました。
- [`state`]($state)が、`key`だけでなく`(key, init)`の組で識別されていた問題を修正しました。
- [番号付きリスト]($enum)のインデント処理を改善しました。マーカーの末尾と同じ位置までインデントする必要がなくなり、マーカーの先頭より空白1つ分多くインデントすればよくなりました。そのため、`12.`のような長いマーカーでも、空白2つのインデントで動作します。
- [`raw`]($raw)ブロックのインデント処理のバグを修正しました。
- 辞書のパースのバグを修正しました。

## 開発
- パーサーと構文木を`typst-syntax`クレートへ分離しました。
- Typstに依存するプロジェクトの`World::today`実装に、CLIのWorldと同じ[バグ](https://github.com/typst/typst/issues/1842)がある場合は、修正が必要になることがあります。
