# バージョン0.14.1（2025年12月3日） { #v0.14.1 }

## PDFエクスポート
- ラベル付き要素へのリンクは、正しく動作しないことがあるというリグレッションを修正しました [LaurenzV/krilla#304](https://github.com/LaurenzV/krilla/issues/304)
- PDFのテキスト属性が誤って書き込まれることがあるバグを修正しました [#7478](https://github.com/typst/typst/issues/7478)
- リンク処理でのクラッシュを修正しました [#7471](https://github.com/typst/typst/issues/7471)
- サイズがゼロのページでのクラッシュを修正しました [#7454](https://github.com/typst/typst/issues/7454)
- 表の[`vline`]($table.vline)や[`hline`]($table.hline)に範囲外のインデックスが指定された場合のクラッシュを修正しました [#7448](https://github.com/typst/typst/issues/7448)
- フォント関連のPDFエクスポートエラーの書式設定でのクラッシュを修正しました [#7460](https://github.com/typst/typst/issues/7460)
- [`footnote`]($footnote)要素や[`place`]($place)要素を検索して文書へ再挿入した場合のクラッシュを修正しました [#7216](https://github.com/typst/typst/issues/7216)
- 無効なメタデータを持つPNGでのクラッシュを修正しました [LaurenzV/krilla#286](https://github.com/LaurenzV/krilla/issues/286), [LaurenzV/krilla#287](https://github.com/LaurenzV/krilla/issues/287)
- 描画順序が`fill-and-stroke`のSVG内のテキストが、誤ってエクスポートされることがあるバグを修正しました [LaurenzV/krilla#292](https://github.com/LaurenzV/krilla/issues/292)
- ブレンディングやマスキングを使用するSVGで、レイヤーの分離に関するバグを修正しました [LaurenzV/krilla#295](https://github.com/LaurenzV/krilla/issues/295)
- 特定の状況で表のヘッダーに誤ったタグが付く問題を修正しました [LaurenzV/krilla#289](https://github.com/LaurenzV/krilla/issues/289)
- 32ビットシステムと64ビットシステムで、生成されるPDFは異なることがあるという問題を修正しました [LaurenzV/krilla#317](https://github.com/LaurenzV/krilla/issues/317), [LaurenzV/krilla#316](https://github.com/LaurenzV/krilla/issues/316), [LaurenzV/krilla#312](https://github.com/LaurenzV/krilla/issues/312)
- PDFエクスポートで使用するJPEGデコーダーを更新し、互換性を改善しました。有効なJPEGが拒否されるケースを修正しました [LaurenzV/krilla#288](https://github.com/LaurenzV/krilla/issues/288)
- PDFの文書情報辞書が空になる場合は、辞書自体を省略するようになりました [LaurenzV/krilla#280](https://github.com/LaurenzV/krilla/issues/280)
- PDFのタグ付けでまれに起きるクラッシュを、コンパイラーのエラーへ変更しました [#7450](https://github.com/typst/typst/issues/7450)

## HTMLエクスポート
- 罫間のある表の[ヘッダー]($table.header)と[フッター]($table.footer)のエクスポートを修正しました [#7332](https://github.com/typst/typst/issues/7332)
- HTMLエクスポートで[`page`]($page)のsetルールを使用した場合、通常の未対応要素の扱いと同じく、エラーではなく警告を出すようになりました [#7513](https://github.com/typst/typst/issues/7513)

## 数式
- `arrow.l.r`を[アクセント]($math.accent)として使用できなくなっていたリグレッションを修正しました [#7481](https://github.com/typst/typst/issues/7481)
- 1文字の文字列が、複数文字の文字列と同じように周囲の空白へ反応しない問題を修正しました [#7276](https://github.com/typst/typst/issues/7276)
- フェンス区切り記号を指定した[`mat`]($math.mat)と[`vec`]($math.vec)の前後の間隔が、空白の有無に依存する問題を修正しました [#7309](https://github.com/typst/typst/issues/7309)
- 水平方向へ引き伸ばしたグリフの高さの計算を修正しました [#7327](https://github.com/typst/typst/issues/7327)

## モデル
- カウンターの状態`{(0,)}`を処理しない見出しの番号付け関数で、エラーが出るリグレッションを修正しました。この状態は最初のレイアウト反復で生じることがあります。通常、Typstはこの種のエラーを自動的に捕捉しますが、このケースでは捕捉していませんでした。[#7459](https://github.com/typst/typst/issues/7459)

## 文章
- 一部のフォントで、[タイポグラフィー用]($super.typographic)のグリフが利用できても上付き文字を合成していたリグレッションを修正しました [#7462](https://github.com/typst/typst/issues/7462)
- 一部のオブリーク体のフォントをイタリック体へ分類していたリグレッションを修正しました [#7483](https://github.com/typst/typst/issues/7483)

## スクリプト記述
- [`array.sorted`]($array.sorted)での不変条件の違反によるクラッシュを修正しました [#7520](https://github.com/typst/typst/issues/7520)
- [`calc.rem`]($calc.rem)、[`calc.rem-euclid`]($calc.rem-euclid)、[`calc.div-euclid`]($calc.div-euclid)、[`calc.quo`]($calc.quo)、[`calc.gcd`]($calc.gcd)でのオーバーフローによるクラッシュを修正しました [#7419](https://github.com/typst/typst/issues/7419)
- WebAssemblyランタイムを更新し、[プラグイン]($plugin)で起こりうるバグを修正しました [#7438](https://github.com/typst/typst/issues/7438)

## コマンドラインインターフェース
- `--deps --deps-format=make`と組み合わせて標準出力へコンパイルした場合（エラーになります）、副作用として空のMake依存関係ファイルが生成されなくなりました [#7246](https://github.com/typst/typst/issues/7246)

## 開発
- 最低サポートRustバージョンを1.89へ引き上げました [#7363](https://github.com/typst/typst/issues/7363)
