# バージョン0.11.0（2024年3月15日）

## 表
- 表が*大幅に*柔軟になりました。まずは新しい[表のガイド]($guides/tables)をご覧ください。
- セルごとに設定する[`table.cell`]($table.cell)要素を追加しました。
- セルを複数の[列]($table.cell.colspan)や[行]($table.cell.rowspan)にまたがらせることができるようになりました。
- 個々のセルの[ストローク]($table.cell.stroke)をカスタマイズできるようになりました。
- table関数の[`align`]($table.align)引数と[`inset`]($table.inset)引数が、`{(x, y) => ..}`関数も受け取れるようになりました。
- 線を手軽にカスタマイズする[`table.hline`]($table.hline)と[`table.vline`]($table.vline)を追加しました。
- 各ページで繰り返す表のヘッダーのための、[`table.header`]($table.header)要素を追加しました。
- 各ページで繰り返す表のフッターのための、[`table.footer`]($table.footer)要素を追加しました。
- 表の新機能は全て、[グリッド]($grid)でも利用できます。
- 罫間に関するバグを修正しました。

_表の機能を開発した[@PgBiel](https://github.com/PgBiel)に感謝します。_

## テンプレート
- テンプレートパッケージを使って、新しいプロジェクトを始められるようになりました。Webアプリのダッシュボードで*テンプレートから開始*をクリックして好きなテンプレートを選ぶか、CLIで`typst init <template>`コマンドを実行してください。[利用できるテンプレートはこちらで探せます]($universe/search/?kind=templates)。
- 後からテンプレートを切り替えやすくなりました。別のテンプレートパッケージからスタイル設定関数をインポートするだけで切り替えられます。
- パッケージの作者が、独自のテンプレートを[パッケージリポジトリ](https://github.com/typst/packages)へ投稿できるようになりました。論文や所属機関向けのテンプレート、独自の作品のテンプレートを共有して、コミュニティーがプロジェクトを始める手助けをしましょう。
- テンプレートとパッケージを、カテゴリーと分野で整理しました。*テンプレートから開始*ウィザードで、どちらの分類でもパッケージを絞り込めます。パッケージの作者は、[カテゴリー](https://github.com/typst/packages/blob/main/CATEGORIES.md)と[分野](https://github.com/typst/packages/blob/main/DISCIPLINES.md)の新しいドキュメントをご覧ください。

## コンテキスト
- _コンテキスト式_を追加しました。まずは[コンテキスト]($context)の章をご覧ください。
- コンテキストを使うと、設定可能なプロパティーへアクセスできます。例えば、`{context text.lang}`で`{set text(lang: "..")}`によって設定した言語を取得できます。
- 次の既存の関数をコンテキスト関数にしました：[`query`]($query)、[`locate`]($locate)、[`measure`]($measure)、[`counter.display`]($counter.display)、[`counter.at`]($counter.at)、[`counter.final`]($counter.final)、[`state.at`]($state.at)、[`state.final`]($state.final)。
- 現在のコンテキストでのカウンターや状態の値を取得する、コンテキストメソッドの[`counter.get`]($counter.get)と[`state.get`]($state.get)を追加しました。
- 現在のコンテキストの[ロケーション]($location)を取得する、コンテキスト関数の[`here`]($here)を追加しました。
- [`locate`]($locate)関数は、セレクターに一意に一致する要素のロケーションを返すようになりました。以前の動作はコンテキスト式へ置き換えられ、互換性のため一時的にのみ利用できます。
- [`counter.at`]($counter.at)メソッドと[`state.at`]($state.at)メソッドが、より柔軟になりました。ロケーションだけでなく、一意に一致する任意の[ロケータブル]($location/#locatable)なセレクター（ラベルなど）を直接受け取ります。
- コンテキストが利用できる場合、[`counter.display`]($counter.display)は不透明なコンテンツを生成する代わりに、番号付けを適用した結果を直接返すようになりました。今後は、コンテキストなしで使用しないでください（廃止予定となる見込み）。
- `state.display`関数は今後使用せず、代わりに[`state.get`]($state.get)を使用してください（廃止予定となる見込み）。
- [`query`]($query)、[`counter.final`]($counter.final)、[`state.final`]($state.final)の`location`引数は、今後使用しないでください（廃止予定となる見込み）。
- `measure`関数の`styles`引数は、今後使用しないでください（廃止予定となる見込み）。
- `style`関数は今後使用せず、代わりにコンテキストを使用してください（廃止予定となる見込み）。
- showルール、レイアウトのコールバック、アウトラインの番号付け関数など、コンテキストが利用できる他のさまざまな箇所でも、正しいコンテキストを提供するようになりました。

## スタイル設定
- 複数の[show-setルール]($styling/#show-rules)の優先順位を修正しました。通常のsetルールと同じ順序で適用するようになりました。
- 同じ要素へのshow-setルール（`{show heading.where(level: 1): set
  heading(numbering: "1.")}`など）が、正しく動作するようになりました。
- 変換するshowルール内で、その要素のプロパティーを設定すること（`{show heading: it => { set heading(..); it }}`など）には、今後**対応しません**。以前も、動作する場合としない場合がありました。代わりにshow-setルールを使用してください。**（破壊的変更）**。
- 自身の出力に一致する文章のshowルールが、正しく動作するようになりました（`` {show "cmd": `cmd`} ``など）。
- showルールへ渡される要素と、検索が返す要素は、特定のフィールドだけでなく、それぞれの要素関数の全フィールドを含むようになりました。
- 設定可能な全てのプロパティーを、[where]($function.where)セレクターで使用できるようになりました。
- [and]($selector.and)セレクターと[or]($selector.or)セレクターを、showルールで使用できるようになりました。
- 以前の[`locate`]($locate)の動作と同じく、showルールとコンテキスト式の内部のエラーは、内省の最後の反復以外では無視するようになりました。
- コンテンツの後にdocumentのsetルールを記述できていたバグを修正しました。

## レイアウト
- レイアウトへ影響を与えるための`reflow`引数を、[`rotate`]($rotate)と[`scale`]($scale)に追加しました。
- [フロート配置]($place.float)や[フロート図表]($figure.placement)の順序が入れ替わってしまうバグを修正しました。
- ページ全体を占めるフロート図表で、文章と図表が重なる問題を修正しました。
- [`hide`]($hide)関数がコンテンツを適切に隠さない、さまざまなケースを修正しました。
- [スタック]($stack)内での[`h`]($h)と[`v`]($v)の使用を修正しました。
- カウンターの更新のような不可視のコンテンツが、それ自体のためだけに可視のブロックを強制的に作らなくなりました。
- 段落の冒頭で、水平方向の間隔の直後に不可視のコンテンツ（カウンターの更新など）が続く場合のバグを修正しました。

## 文章
- 文章の[`stroke`]($text.stroke)プロパティーを追加しました。
- セルビア語とカタルーニャ語の基本的な国際化対応を追加しました。
- 現代の日本語の[番号付け]($numbering)方式に対応しました。
- 特定のフォントの誤ったさまざまなメタデータに、補正を追加しました。
- 段落内で[文章の方向]($text.dir)を上書きできるようになりました。
- デンマーク語の[スマートクォート]($smartquote)を修正しました。
- 改行の隣のフォントフォールバックを修正しました。
- JIS形式の日本語の句読点の幅の調整を修正しました。
- 「Listing」のフィンランド語訳を修正しました。
- 複数の文章の装飾（下線など）の重なり順を修正しました。
- 連続するsetルールで、文章の[フォントのフィーチャー]($text.features)を上書きできないバグを修正しました。

## モデル
- 一連のコンテンツの見出しレベルを増減するための、[`depth`]($heading.depth)引数と[`offset`]($heading.offset)引数をheadingに追加しました。見出し構文は、`level`ではなく`depth`を設定するようになりました。**（破壊的変更）**。
- リストの[マーカー]($list.marker)は、デフォルトで繰り返すようになりました。
- [`quote`]($quote)関数が、言語と入れ子の状態に応じて、より確実に正しい引用符を選ぶようになりました。
- [用語リスト]($terms)のデフォルトのshowルールに関する、インデントのバグを修正しました。

## 数式
- インライン数式が、適切な位置で自動的に改行するようになりました。
- 数式に[`number-align`]($math.equation.number-align)引数を追加しました。
- アクセントの[`size`]($math.accent.size)を、ベースに対する相対値で調整できるようになりました。
- アクセントの位置を改善しました。
- [プライム]($math.primes)は、デフォルトで常に[scripts]($math.scripts)として付けるようになりました。
- 数式の`[$f'$]`構文の実体である[`math.primes`]($math.primes)要素を公開しました。
- 数式モードが、[`strong`]($strong)と[`emph`]($emph)の影響を受けなくなりました。
- [分数]($math.frac)の下の[`attach`]($math.attach)を修正しました。
- [`math.class`]($math.class)が、limitsの自動配置へ影響しない問題を修正しました。
- [`lr`]($math.lr)グループ内の弱い間隔を修正しました。
- Cambria Mathフォントの大型演算子のレイアウトを修正しました。
- ヘブライ語記号のコードポイントの、数式でのスタイル設定を修正しました。

## 記号
- `nabla`の別名として`gradient`を追加しました。
- `diff`の別名として`partial`を追加しました。`diff`は将来的に廃止予定となります。
- `colon.double`、`gt.approx`、`gt.napprox`、`lt.approx`、`lt.napprox`を追加しました。
- `arrow.r.tilde`と`arrow.l.tilde`を追加しました。
- `tilde.dot`を追加しました。
- `forces`と`forces.not`を追加しました。
- `space.nobreak.narrow`を追加しました。
- `lrm`（左から右へのマーク）と`rlm`（右から左へのマーク）を追加しました。
- `star.stroked`記号を修正しました。以前はコードポイントが誤っていました。

## スクリプト記述
- 配列を辞書式順序で比較できるようになりました。
- 長さに、コンテキストメソッドの[`to-absolute`]($length.to-absolute)を追加しました。
- [`calc.root`]($calc.root)を追加しました。
- [`int.signum`]($int.signum)メソッドと[`float.signum`]($float.signum)メソッドを追加しました。
- [`float.is-nan`]($float.is-nan)メソッドと[`float.is-infinite`]($float.is-infinite)メソッドを追加しました。
- [`int.bit-not`]($int.bit-not)、[`int.bit-and`]($int.bit-and)、[`int.bit-or`]($int.bit-or)、[`int.bit-xor`]($int.bit-xor)、[`int.bit-lshift`]($int.bit-lshift)、[`int.bit-rshift`]($int.bit-rshift)メソッドを追加しました。
- [`array.chunks`]($array.chunks)メソッドを追加しました。
- [辞書のコンストラクター]($dictionary/#constructor)でモジュールを辞書へ変換し、内容へ動的にアクセスできるようになりました。
- 行の表現方法を設定する[`row-type`]($csv.row-type)引数を`csv`関数に追加しました。
- [XMLのパース]($xml)で、DTD（文書型定義）を許可するようになりました。
- [`str`]($str)と[`repr`]($repr)による負の数値の書式設定を改善しました。
- forループで[バイト列]($bytes)を反復処理できるようになりました。
- forループ内のパターンマッチングのバグを修正しました。
- ラベルが[`{.fields()}`]($content.fields)の辞書に含まれないバグを修正しました。
- 名前のない引数シンクが余分な引数を受け取らないバグを修正しました。
- ストロークの`repr`出力の誤記を修正しました。

## 構文
- 入れ子の[分割パターン]($scripting/#bindings)に対応しました。
- 特殊な空白（細い空白や改行禁止の空白など）を、通常の空白へまとめず、そのままパースするようになりました。**（破壊的変更）**。
- 韓国語の文章で、空白を追加せずに強調構文を使用できるようになりました。**（破壊的変更）**。
- [`context`]($context)トークンがキーワードになり、識別子として使用できなくなりました。**（破壊的変更）**。
- ブロックコメント内で、行コメントを入れ子にできなくなりました。**（破壊的変更）**。
- `x.)`をフィールドアクセスとして扱うバグを修正しました。
- マークアップで、文章の要素が波括弧をまたげるようになりました。
- 関数名を括弧で囲んだ場合に、誤ったパース結果となる問題を修正しました。
- 分割パターン、配列、辞書のパースのさまざまなバグを修正しました。

## ツールと診断
- クリックからのジャンプが、[`raw`]($raw)テキスト内でも正しく動作するようになりました。
- メソッドが存在しない場合に、フィールドへのアクセスを提案するようになりました。
- 辞書に格納した関数を呼び出す際のヒントを改善しました。
- 配列や辞書の、変更可能なアクセサー関数のエラーを改善しました。
- コンストラクターを持たない型のコンストラクターを呼び出した場合の、エラーメッセージを修正しました。
- 異なる辺のストロークを指定する入れ子の辞書で、エラーメッセージがわかりにくい問題を修正しました。
- 異なる名前空間にある同名の複数のパッケージの、自動補完を修正しました。

## 視覚化
- [`image`]($image)関数が、画像を本来のサイズ以上に拡大しなくなりました。
- [`image`]($image)関数が、EXIFメタデータ内の回転を反映するようになりました。
- SVGフィルターに対応しました。
- [`luma`]($color.luma)の色にアルファ成分を追加しました。
- [`color.transparentize`]($color.transparentize)メソッドと[`color.opacify`]($color.opacify)メソッドを追加しました。
- [`color.negate`]($color.negate)関数を改善しました。
- `highlight`関数に[`stroke`]($highlight.stroke)引数と[`radius`]($highlight.radius)引数を追加しました。
- デフォルトの[`highlight`]($highlight)の色を、透明になるよう変更しました。
- CMYKからRGBへの変換を、カラーマネジメントの対象にしました。
- Oklch色空間のグラデーションでのクラッシュを修正しました。
- 色相に基づく色空間での混色を修正しました。
- 色の変換のバグを修正しました。
- SVGのサイズを丸めなくなり、縦横比がわずかにずれる問題を防ぐようになりました。
- SVGに関するその他のバグをいくつか修正しました。
- [`color.components`]($color.components)が、値を丸めなくなりました。

## エクスポート
- PDFに、見出しのラベルから生成した名前付きの移動先を含めるようになりました。
- 外部ツールで個々のページを抽出、変更しやすくするため、PDFの内部構造を変更しました。これにより、AppleのプレビューでのTypstのPDFに関するバグを回避します。
- `{set document(date: none)}`を設定した場合、Typstが生成するPDFをバイト単位で再現できるはずです。
- PDFの注釈に、欠落していたフラグを追加しました。
- PDFエクスポートでのグラデーションの複数のバグを修正しました。
- PDFエクスポートでのパターンのバグを修正しました。
- PDFエクスポートでのグレースケール画像の埋め込みのバグを修正しました。
- PDFエクスポートでのCFFフォントのTo-Unicodeマッピングのバグを修正しました。
- PDFアウトラインの生成のバグを修正しました。
- PDFエクスポートで、出力を再現できなくしていたソートのバグを修正しました。
- PNGエクスポートでの透明な文章のバグを修正しました。
- エクスポートしたSVGファイルの最上位の`width`と`height`に、単位を含めるようになりました。

## コマンドラインインターフェース
- CLIフラグでの[入力]($category/foundations/sys)の受け渡しに対応しました。
- ファイル名として`-`を渡すと、Typstが標準入力から読み込むようになりました。
- ネットワーク経由の取得に、システム標準のTLS実装を使用するようになりました。一般に、より堅牢になるはずです。
- 監視モードで、以前は存在しなかったファイルの作成を正しく検出するようになりました。
- 出力を色付きにするかどうか設定する`--color`フラグを追加しました。
- パッケージのダウンロードに使用するユーザーエージェントを修正しました。
- 同梱フォントを最新バージョンへ更新しました。

## 開発
- OpenSSLを動的ではなく静的にリンクするかどうか設定する、`--vendor-openssl`をCLIへ追加しました。WindowsとAppleのプラットフォームには適用されません。
- 古いトレース用フラグと、その詳細度のフラグをCLIから削除しました。
- CLIの以前のフレームグラフによるプロファイリングに代わる、新しい`--timings`フラグを追加しました。
- 言語と標準ライブラリーのドキュメントをJSONとして抽出する、最小限のCLIを`typst-docs`クレートに追加しました。
- `typst_pdf::export`関数の`ident`引数を、`Option`から`Smart`へ変更しました。Webアプリのように安定した識別子を提供できる場合にのみ、`Smart::Custom`を設定してください。CLIは`Smart::Auto`を設定します。
