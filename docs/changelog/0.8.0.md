# バージョン0.8.0（2023年9月13日）

## スクリプト記述
- プラグイン（[@astrale-sharp](https://github.com/astrale-sharp)と[@arnaudgolfouse](https://github.com/arnaudgolfouse)に感謝します）
  - WebAssemblyへコンパイルした[プラグイン]($plugin)をTypstで読み込めるようになりました。
  - そのため、WebAssemblyへコンパイルできるものは全て、プラグインとして読み込めます。
  - プラグインは完全に隔離されており、ファイルシステムやネットワークへアクセスできません。
  - プラグインを[パッケージ]($scripting/#packages)の一部として配布できます。
  - プラグインはWebアプリでも同じように動作します。
- 型が第一級の値になりました。**（破壊的変更）**。
  - [型]($type)自体が値になりました。
  - コンストラクターを持つ一部の型は、関数のように呼び出せます。例えば、[`int`]($int)と[`str`]($str)が該当します。
  - 型の検査は、以前の`{type(10) == "integer"}`ではなく、`{type(10) == int}`という形式になりました。パッケージの作者が更新する時間を確保するため、以前の方法との[互換性]($type/#compatibility)はしばらく維持しますが、いずれ削除します。
  - メソッドは、型のスコープ内の関数を呼び出すための構文糖衣になりました。つまり、`{"hello".len()}`は`{str.len("hello")}`と同じです。
- `as`による[`import`]($scripting/#modules)時の名前変更に対応しました。
- [`duration`]($duration)型を追加しました。
- [CBOR]($cbor)のエンコードとデコードに対応しました。
- データ形式をバイト列との間で変換するエンコード・デコード関数として、[`json.decode`]($json.decode)、[`json.encode`]($json.encode)、その他の形式向けの同様の関数を追加しました。
- [`array.intersperse`]($array.intersperse)関数を追加しました。
- [`str.rev`]($str.rev)関数を追加しました。
- `calc.tau`定数を追加しました。
- [バイト列]($bytes)を結合、加算できるようにしました。
- [`array.zip`]($array.zip)関数を可変長引数に対応させました。
- `mode`が`{"math"}`の場合の[`eval`]($eval)のバグを修正しました。
- 文字列の[`ends-with`]($str.ends-with)関数のバグを修正しました。
- 分割とbreak、continue、returnを組み合わせた場合のバグを修正しました。
- [双曲線関数]($calc.cosh)の引数の型を修正し、角度を受け取らなくなりました。**（破壊的変更）**。
- 一部の色のメソッドの名前を変更しました。`rgba`は`to-rgba`、`cmyk`は`to-cmyk`、`luma`は`to-luma`になりました。**（破壊的変更）**。

## エクスポート
- SVGエクスポートを追加しました（[@Enter-tainer](https://github.com/Enter-tainer)に感謝します）。
- PDFへのフォント埋め込みに関するバグを修正しました。
- PDFで、[ページの番号付け]($page.numbering)のスタイルを反映したページラベルに対応しました。

## 文章とレイアウト
- 背景色で文章を強調する[`highlight`]($highlight)関数を追加しました。
- 正多角形を描く[`polygon.regular`]($polygon.regular)関数を追加しました。
- [`raw`]($raw)要素内のタブに対応し、[`tab-width`]($raw.tab-size)パラメーターを追加しました。
- レイアウトエンジンが、1単語だけの最終行（runts）を避けるようになりました。
- フィンランド語の翻訳を追加しました。
- ポーランド語のハイフネーションに対応しました。
- 異なる種類のスマートクォートが連続する場合の処理を改善しました。
- page関数の[`number-align`]($page.number-align)引数で、垂直方向の配置を修正しました。**（破壊的変更）**。
- カウンター更新後の弱い改ページを修正しました。
- テキストのフォントが「New Computer Modern」の場合、SVG内のテキストが欠落する問題を修正しました。
- 中国語の翻訳を修正しました。
- showルール内の空の文章でのクラッシュを修正しました。
- 数字とコンマの後に改行がある場合の、先頭の空白を修正しました。
- 段組みやその他のコンテナー内のフロート要素の配置を修正しました。
- ボックスを1つだけ含むブロックのサイズ決定を修正しました。

## 数式
- [拡大行列]($math.mat.augment)に対応しました。
- 誤検出が多すぎたため、`|`や`||`などのフェンスの自動対応付けを削除しました。代わりに、[`abs`]($math.abs)や[`norm`]($math.norm)などの関数、または明示的な[`lr`]($math.lr)の呼び出しを使用できます。**（破壊的変更）**。
- 数式内の小数点を含む数値の後の間隔を修正しました。
- 下付き文字のプライムに関するバグを修正しました。
- 弱い間隔を修正しました。
- 数式内の文章に改行が含まれる場合のクラッシュを修正しました。

## ツールと診断
- 辞書に格納した関数を、追加の括弧なしで呼び出そうとした場合のヒントを追加しました。
- 番号のない数式を参照する場合のヒントを修正しました。
- 一部の診断（SVGのデコードに失敗した場合など）に詳細を追加しました。

## コマンドラインインターフェース
- CLI自体を更新する`typst update`コマンドを追加しました（[@jimvdl](https://github.com/jimvdl)に感謝します）。
- パッケージと更新のダウンロードの進捗表示を追加しました。
- 出力形式を明示的に指定する`--format`引数を追加しました。
- CLIが環境変数によるプロキシー設定を反映するようになりました。また、独自のCA証明書を設定する`--cert`オプションを追加しました。
- フィールドが存在せず、`typst query`で`--one`を指定した場合のクラッシュを修正しました。

## その他の改善
- [ページ設定ガイド]($guides/page-setup)を追加しました。
- 図表のカスタマイズを簡単にする[`figure.caption`]($figure.caption)関数を追加しました。図表のshowルールと手動のアウトラインで、`it.caption`が補足語を含むキャプション全体をレンダリングするようになったため、**破壊的変更**です。
- `caption-pos`引数を`figure.caption`関数へ移動し、名前を`position`へ変更しました。**（破壊的変更）**。
- `figure.caption`関数に[`separator`]($figure.caption.separator)引数を追加しました。
- and/orとbefore/afterの[セレクター]($selector)の組み合わせに対応しました。
- パッケージが、動作に必要な[コンパイラーの最低バージョン](https://github.com/typst/packages#package-format)を指定できるようになりました。
- マークアップ内の`[#let]`式で、メソッド呼び出しを独立した行へ移動できていたパーサーのバグを修正しました。**（破壊的変更）**。
- 参考文献の文頭のみ大文字にする変換と、タイトルケースへの変換のバグを修正しました。
- 英数字形式と著者・タイトル形式の参考文献スタイルの補足語を修正しました。
- APA参考文献スタイルのオフバイワンエラーを修正しました。

## 開発
- `Span`と`FileId`の型安全性を高め、`World`の実装者が全てのエラー条件を処理する必要があるようにしました。
