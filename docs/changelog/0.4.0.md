# バージョン0.4.0（2023年5月20日）

## 脚注
- 脚注に対応しました。
- [`footnote`]($footnote)関数で脚注を挿入します。
- [`footnote.entry`]($footnote.entry)関数で脚注の一覧をカスタマイズできます。
- `{"chicago-notes"}`の[引用スタイル]($cite.style)が利用できるようになりました。

## ドキュメント
- [LaTeXユーザー向けガイド]($guides/for-latex-users)を追加しました。
- 省略可能な引数のデフォルト値を表示するようになりました。
- 「このページの内容」のアウトラインを充実させました。
- 検索キーワードへの初期対応を追加しました。「Table of Contents」で[アウトライン]($outline)関数を検索できるようになりました。キーワードの追加提案も歓迎します。
- 検索結果の順位付けの問題を修正しました。
- その他にも、多くの小さな問題を修正しました。

## 数式
- **破壊的変更**：数式内の配置ポイント（`&`）が、左揃えと右揃えを交互に使うよう変更しました。
- Unicodeで根号を記述できるようになりました。例えば、`[$root(x+y)$]`は`[$√(x+y)$]`とも書けるようになりました。
- [`attachment`]($math.attach)の垂直方向の配置の不揃いを修正しました。
- 装飾された要素の間隔（[取り消し線を引いた]($math.cancel)演算子の前後の間隔など）を修正しました。
- 伸縮可能な記号のスタイル設定を修正しました。
- `tack.r.double`、`tack.l.double`、`dotless.i`、`dotless.j`の[記号]($category/symbols/sym)を追加しました。
- 記号へのshowルール（`{show sym.tack: set text(blue)}`など）を修正しました。
- 前のリリースで行うはずだった`ast.op`から`ast`への名前変更の漏れを修正しました。

## スクリプト記述
- 関数スコープを追加しました。モジュールと同様に、関数が自身のスコープに関連する定義を保持できるようになりました。例えば、新しい[`assert.eq`]($assert.eq)関数は、[`assert`]($assert)関数のスコープに属します。現時点では、関数スコープは組み込み関数でのみ利用できます。
- 等しいことや等しくないことをより簡単に検証でき、より役立つエラーメッセージを出す[`assert.eq`]($assert.eq)関数と[`assert.ne`]($assert.ne)関数を追加しました。
- [箇条書きリスト]($list.item)、[番号付きリスト]($enum.item)、[用語リスト]($terms.item)の項目を、それぞれの関数のスコープで公開しました。
- [文字列]($str.at)、[配列]($array.at)、[辞書]($dictionary.at)、[コンテンツ]($content.at)の`at`メソッドで、デフォルト値を指定できるようになりました。
- [`replace`]($str.replace)で関数を受け取れるようになりました。一致するたびにその関数を呼び出します。
- [置換]($str.replace)文字列を修正しました。以前は意図せず使えていたキャプチャーグループ用の特殊なドル記号構文を廃止し、文字列を完全にそのまま挿入するようになりました。
- 分割パターンの末尾にあるプレースホルダーのバグを修正しました。
- パラメーターの分割におけるアンダースコアのバグを修正しました。
- パターンを入れ子にした場合や、無効なパターンにカーソルを合わせた場合のクラッシュを修正しました。
- [整数]($int)や[浮動小数点数]($float)への変換に失敗した場合のエラーメッセージを改善しました。

## 文章とレイアウト
- CJKの句読点の高度な調整を実装しました。
- CJKの句読点の[ぶら下げ]($text.overhang)を無効にしました。
- 繁体字中国語の基本的な翻訳を追加しました。
- rawブロック内の文章の[配置]($raw.align)を修正しました。例えば図表を使ってrawブロックを中央配置しても、文章自体は左揃えを維持するようになりました。
- 表のセルの[配置]($table.align)と[塗りつぶし]($table.fill)を列ごとに設定する際、関数の代わりとして配列を渡せるようになりました。
- 図表の[`kind`]($figure.kind)の自動検出を修正しました。
- [番号付きリストの番号]($enum.number-align)の配置を設定できるようにしました。デフォルトは`end`です。
- 図表内のブロックへのshow-setルールで、図表を分割可能にできるようになりました。
- 右から左に読む言語のスマートクォートについて、初期の修正を加えました。

## エクスポート
- コピーや検索ができるよう、PDFエクスポートでの合字を修正しました。
- 画像がICCプロファイルを持つ場合、エクスポートしたPDFへ埋め込むようになりました。
- 太さがゼロのストロークのエクスポートを修正しました。

## Webアプリ
- プロジェクトにフォルダーを含められるようになりました。
- ファイルパネルへのドラッグ＆ドロップによるアップロードを追加しました。
- ファイルパネルからエディターへファイルをドラッグすると、Typstファイルに挿入できます。
- コンピューター上の画像やその他のファイルをコピーして、エディターへ直接貼り付けられるようになりました。
- 確認メールを再送するボタンを追加しました。
- ダークモードでプレビューの色を反転するオプションを追加しました。
- 読み込み画面とヘルプメニューにヒントを追加しました。追加の提案も歓迎します。
- YAMLファイルのシンタックスハイライトを追加しました。
- 多くのボタンで、マウスの中央ボタンをクリックして新しいタブで開けるようになりました。
- プロジェクト名として使用できる名前を増やしました。
- Vimモードのキーバインドが上書きされる問題を修正しました。
- ファイルのアップロードなどに関する多くのバグを修正しました。

## その他の改善
- カウンター、状態、検索のパフォーマンスを改善しました。
- 再コンパイルを効率化するため、インクリメンタルパースを改善しました。
- 参考文献で`.yml`に加えて`.yaml`拡張子に対応しました。
- CLIは、出力先がTTYの場合にのみエスケープコードを出力するようになりました。
- `typst`クレートの利用者向け：`Document`が再び`Sync`になり、`World`が`'static`である必要もなくなりました。
