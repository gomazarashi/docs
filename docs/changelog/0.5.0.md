# バージョン0.5.0（2023年6月9日）

## 文章とレイアウト
- [`raw`]($raw)のシンタックスハイライトで、さらに多くの言語に対応しました。
- 韓国語の[番号付け]($numbering)に対応しました。
- さらにいくつかの言語（NL、SV、DA）の基本的な国際化対応を追加しました。
- 東アジア言語の改行処理を改善しました。
- アウトラインの[`indent`]($outline.indent)プロパティーの機能を拡張しました。
- 段組み内の脚注を修正しました。
- [脚注]($footnote)に関する改ページのバグを修正しました。
- リスト、表、図表での脚注の処理のバグを修正しました。
- CJKの句読点の調整に関するバグを修正しました。
- 角丸の長方形でのクラッシュを修正しました。
- [`line`]($line)要素の配置を修正しました。

## 数式
- **破壊的変更**：数式の[アタッチメント]($math.attach)の構文規則を改善しました。`[$f^abs(3)$]`は、`[$(f^abs)(3)$]`ではなく`[$f^(abs(3))$]`として解析されるようになりました。曖昧さを解消するには、`[$f^zeta (3)$]`のように空白を追加してください。
- 数式の[サイズを強制する]($category/math/sizes)コマンド（[`display`]($math.display)など）を追加しました。
- [参照]($ref)で使用する[`supplement`]($math.equation.supplement)パラメーターを[`equation`]($math.equation)に追加しました。
- 新しい[記号]($category/symbols/sym)として、`bullet`、`xor`、`slash.big`、`sigma.alt`、`tack.r.not`、`tack.r.short`、`tack.r.double.not`を追加しました。
- 行列内の記号のバグを修正しました。
- [`attach`]($math.attach)関数でのクラッシュを修正しました。

## スクリプト記述
- 新しい[`datetime`]($datetime)型と、現在の日付を取得する[`datetime.today`]($datetime.today)を追加しました。
- [`str.from-unicode`]($str.from-unicode)関数と[`str.to-unicode`]($str.to-unicode)関数を追加しました。
- コンテンツの[`fields`]($content.fields)メソッドを追加しました。
- [`str`]($str)関数に`base`パラメーターを追加しました。
- [`calc.exp`]($calc.exp)と[`calc.ln`]($calc.ln)を追加しました。
- 特定の底での[`calc.pow`]($calc.pow)と[`calc.log`]($calc.log)の精度を改善しました。
- 辞書の[削除]($dictionary.remove)順序を修正しました。
- [文字列]($str.at)と[コンテンツ]($content.at)の`.at(default: ..)`を修正しました。
- スタイル設定された要素へのフィールドアクセスを修正しました。
- 廃止予定だった`calc.mod`関数を削除しました。

## コマンドラインインターフェース
- `typst compile source.typ output-{n}.png`によるPNGエクスポートを追加しました。文書が複数ページの場合は、出力パスに`[{n}]`を含める必要があります。
- Unix形式の簡潔な診断を出力する`--diagnostic-format=short`を追加しました。
- 標準エラー出力がTTYでない場合、カラーコードを出力しなくなりました。
- 存在しないファイルを指定して起動した場合、正しい終了ステータスを設定するようになりました。
- Typstファイル内のUTF-8 BOMを無視するようになりました。

## その他の改善
- 区切り記号の不一致に関するエラーを改善しました。
- 長さの比較に失敗した場合のエラーメッセージを改善しました。
- Appleのプレビューで画像が表示されないバグを修正しました。
- PDFアウトラインの複数のバグを修正しました。
- [`hide`]($hide)内の引用やその他の検索可能な要素を修正しました。
- [参照の補足語]($ref.supplement)に関するバグを修正しました。
- Nix flakeを修正しました。
