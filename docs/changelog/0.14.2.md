# バージョン0.14.2（2025年12月12日） { #v0.14.2 }

## セキュリティー
- [プラグイン]($plugin)の実行に使用するWebAssemblyランタイムを更新しました。Typst 0.14.0と0.14.1で使用しているバージョンには、メモリー処理の脆弱性があります。調査によると、実際にこの脆弱性を悪用するのは非常に困難ですが、理論上は悪用できる可能性があります。いずれにせよ、**Typst 0.14.2へのアップグレードを推奨します。** 特にローカルで利用している方に推奨します。Webアプリの場合、ブラウザーによる追加の保護があるため、致命的なバグにはなりません。

  Typst 0.13.1以前は、この脆弱性の影響を受けません。

  *技術的な詳細*：0.14.0と0.14.1で使用している[`wasmi`](https://github.com/wasmi-labs/wasmi/) WebAssemblyランタイムには、特定のメモリー拡張の状況で、解放後のメモリーを使用する*use-after-free*バグがあります。具体的には、プラグインがメモリーを拡張しようとしたものの、要求した量のメモリーを確保できなかった場合に発生します。調査によると、WebAssemblyのリニアメモリーは技術的に常に4GBへ制限されており、現在のオペレーティングシステムでは4GBのメモリー確保要求が失敗することはまれなので（通常はRAMが逼迫していても失敗しません）、実際にこのバグを引き起こすのは困難です。また、バグが発生しても、実際の悪用につなげるのは依然として非常に困難です。それでも、悪用の可能性から保護するため、Typst 0.14.2へのアップグレードを推奨します。

## 診断
- 要素同士を比較できず[`array.sorted`]($array.sorted)が失敗した場合のヒントを追加しました。このヒントは、Typst 0.14.1で内部のソート処理が変わったことで表面化した、ユーザーコードのバグを修正するのに役立ちます。
