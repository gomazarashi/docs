# バージョン0.11.1（2024年5月17日）

## セキュリティー
- パスが既知の画像ファイルを、プロジェクトディレクトリーの外にあってもPDFへ埋め込める脆弱性を修正しました。

## 参考文献
- 2回目以降の引用でのet-alの処理を修正しました。
- 著者のない引用や参考文献への参照で、タイトルを省略する処理を修正しました。
- 区切り文字のない引用スタイルでのイニシャルの処理を修正しました。
- 脚注内の引用のバグを修正しました。

## 文章とレイアウト
- [`first-line-indent`]($par.first-line-indent)と[`outline`]($outline)の組み合わせを修正しました。
- 行頭と行末のCJKの句読点の圧縮を修正しました。
- 寸法が負の[長方形]($rect)の処理を修正しました。
- 明示的なサイズを持つコンテナー内の[`path`]($path)のレイアウトを修正しました。
- 右から左に読む段落で、[`raw`]($raw)テキストが崩れる問題を修正しました。
- 言語が`typ`または`typc`の`raw`テキストでのタブのレンダリングを修正しました。
- 単一のバッククォートで囲まれた、複数行の`raw`テキストのハイライトを修正しました。
- `raw`ブロックではみ出した行のインデントを修正しました。
- `raw`テキストがバッククォートで終わる場合の余分な空白を修正しました。

## 数式
- 右から左に読む段落で、[数式]($math.equation)が崩れる問題を修正しました。
- [黒板太字]($math.bb)の文字が欠落する問題を修正しました。
- 2次元の数式引数リスト内の、空の引数でのエラーを修正しました。
- さまざまな文字について、[`mid`]($math.mid)による伸縮を修正しました。
- 数式内の配置ポイントが`{set align(..)}`の影響を受ける問題を修正しました。

## エクスポート
- PDFアウトラインの[スマートクォート]($smartquote)を修正しました。
- PDF内の、間隔を持つ[パターン]($tiling)を修正しました。
- [ページの番号付け]($page.numbering)を一度有効にしてから無効化した場合、PDFのページラベルが誤る問題を修正しました。

## スクリプト記述
- 外部データファイルの大きな数値でオーバーフローする問題を修正し、代わりに浮動小数点数へ変換するようになりました。
- 文字列全体が一致した場合の[`{str.trim(regex, at: end)}`]($str.trim)を修正しました。

## その他
- 特定の図形と太さでストロークが変形する問題を修正しました。
- コードモードの改行処理を修正しました。メソッドの連続した呼び出しの途中や、`if`分岐と`else`キーワードの間に、コメントを記述できるようになりました。
- インクリメンタルな再パースの非効率な処理を修正しました。
- 相対パスでのファイルのインポートの自動補完を修正しました。
- 自動補完の処理でのクラッシュを修正しました。
- `typst init`が表示するパスとエントリーポイントが、適切にエスケープされていないバグを修正しました。
- ドキュメントのさまざまな誤りを修正しました。
