# バージョン0.10.0（2023年12月4日）

## 参考文献管理
- CSLスタイルで指定されている場合、引用をまとめる処理（`[[1], [2], [3]]`ではなく`[[1]-[3]]`とするなど）に対応しました。
- 引用のまとまりの後に余分な空白が入るバグを修正しました。
- 参考文献内のリンクへのshowルールを修正しました。
- 引用へのshow-setルールを修正しました。
- 一部のシステムで起きていた参考文献関連のクラッシュを修正しました。
- GB/T 7714系スタイルの名前を7114から7714へ訂正しました。
- 一部の参考文献スタイルでタイトルが欠落する問題を修正しました。
- 一部のスタイルでの巻の表示を修正しました。
- 一部のスタイル（APAなど）での寄稿者の区切り記号の順序を修正しました。
- 英数字スタイルの動作を修正しました。
- GB/T 7714スタイルの複数のバグを修正しました。
- Hayagrivaの値のエスケープを修正しました。
- Hayagrivaファイルの日付が空の場合のクラッシュを修正しました。
- 数式ブロックの前後の間隔のバグを修正しました。
- そのまま表示するテキストやアポストロフィーの後の、タイトルケースへの書式設定を修正しました。
- `.bib`ファイルのページ範囲に、任意の文字列を指定できるようになりました。
- `.bib`ファイル内の複数行の値を、正しくパースするようになりました。
- `.bib`ファイル内の項目のキーで、より多くの文字を使用できるようになりました。
- `.bib`ファイルの日付が空の場合のエラーメッセージを修正しました。
- `.bib`ファイルで、先頭をゼロで埋めずに、4桁以外の年を指定できるようになりました。
- `.bib`ファイルで、引用符などのより多くのLaTeXコマンドを反映するようになりました。

## 視覚化
- 塗りつぶしやストロークでの[パターン]($tiling)に対応しました。
- 色の[`components`]($color.components)関数の`alpha`パラメーターが、名前付きパラメーターになりました。**（破壊的変更）**。
- [Oklch]($color.oklch)色空間に対応しました。
- 異なる色空間の色の間の変換を改善しました。
- [Oklab]($color.oklab)のクロマ成分の制限を撤廃しました。
- ストロークのないブロックやボックスの[クリッピング]($block.clip)を修正しました。
- 数式の[グラデーション]($gradient)のバグを修正しました。
- 文章のグラデーションの回転に関するバグを修正しました。
- PDFのグラデーションの色のバグを修正しました。
- Oklabのクロマ成分を比率で指定する際の基準値を修正しました。
- Oklabの色の反転を修正しました。

## 文章とレイアウト
- 空白がなくても、CJKの文章で`*`構文と`_`構文による強調を使用できるようになりました。
- ギリシャ語とエストニア語の基本的な国際化対応を追加しました。
- 中国語、フランス語、ロシア語での、デフォルトの[図表のキャプションの区切り文字]($figure.caption.separator)を改善しました。
- ロシア語のデフォルトの[図表の補足語]($figure.supplement)を、短い形式へ変更しました。
- 改行前と[`locate`]($locate)呼び出し内の、[CJKとラテン文字の間隔]($text.cjk-latin-spacing)を修正しました。
- リンクの末尾の改行処理を修正しました。

## 数式
- 区切り記号を、周囲の[`lr`]($math.lr)グループの高さまで拡大する[`mid`]($math.mid)関数を追加しました。
- [`op`]($math.op)関数が、文字列だけでなく任意のコンテンツを受け取れるようになりました。
- [数式の配置]($category/math/#配置)のドキュメントを改善しました。
- 記号を関数のように使用した場合（`pi(a,b,)`など）、末尾のカンマが取り込まれてしまう問題を修正しました。

## スクリプト記述
- 識別子でない辞書のキーを、式として解釈するようになりました。例えば、`{((key): value)}`は動的なキーを持つ辞書を作成します。
- [`stroke`]($stroke)型に、値をストロークへ変換したり、構成要素からストロークを作成したりするコンストラクターを追加しました。
- [`arguments`]($arguments)型のコンストラクターを追加しました。
- [`calc.div-euclid`]($calc.div-euclid)関数と[`calc.rem-euclid`]($calc.rem-euclid)関数を追加しました。
- [`arguments`]($arguments)の等価性を修正しました。
- [`cmyk`]($color.cmyk)の色の[`repr`]($repr)を修正しました。
- 図表のキャプション、アウトラインの項目、脚注の項目など、提供される要素でのクラッシュを修正しました。

## ツールと診断
- 自身の出力に一致するshowルールで、クラッシュではなく適切なエラーメッセージを出すようになりました。これは最初の段階で、将来的にはそのまま動作するようにする予定です。
- 深すぎる、または無限に入れ子になったレイアウトで、クラッシュではなくエラーメッセージを出すようになりました。
- 無効な識別子へのヒントを追加しました。
- 手動で作成した脚注やアウトラインの項目を使用しようとした場合のヒントを追加しました。
- 型の自動補完で、欠落していた詳細を追加しました。
- 位置引数が必要な箇所で、名前付き引数を渡した場合のエラーメッセージを改善しました。
- クリックからのジャンプが、rawブロックでも動作するようになりました。

## エクスポート
- 文書の[`date`]($document.date)を手動で設定した場合、PDFのコンパイル出力を再びバイト単位で完全に再現できるようになりました。
- SVGの色のエクスポートを修正しました。
- 複数の[著者]($document.author)がいる場合の、PDFメタデータのエンコードを修正しました。

## コマンドラインインターフェース
- `typst watch`がファイルを取り違え、更新を検出できない重大なバグを修正しました。
- `typst update`でのリリースメタデータの取得が、プロキシー設定を反映するようになりました。
- Windowsでパスに空白が含まれる場合の、`--open`フラグのバグを修正しました。
- `TYPST_FONT_PATHS`環境変数に複数のパスを指定できるようになりました。Windowsでは`;`、その他では`:`で区切ります。
- 埋め込みのNew Computer Modernフォントをバージョン4.7へ更新しました。
- メインファイルに無効なUTF-8が含まれていても、監視プロセスが停止しなくなりました。

## その他の改善
- PDFエクスポートの画像エンコードを並列化しました。
- パフォーマンスを向上させるため、コンテンツの内部表現を改善しました。
- 内省（検索、カウンターなど）のパフォーマンスを最適化しました。
- [文書のタイトル]($document.title)で、文字列だけでなく任意のコンテンツを指定できるようになりました。
- 番号付きリストの[`number-align`]($enum.number-align)パラメーターが、垂直方向の配置も受け取れるようになりました。
- [引用]($quote)要素のセレクターを修正しました。
- マークアップ内の`[#return]`式のパースを修正しました。
- インライン数式が数式のアウトラインに表示されるバグを修正しました。
- [`raw`]($raw)ブロックでのCRLFに関する潜在的な問題を修正しました。
- 中国語の番号付けが255を超えられないバグを修正しました。

## 開発
- `typst`と`typst-library`を統合し、`typst-pdf`、`typst-svg`、`typst-render`を独立したクレートへ分離しました。
- Nix flakeで`typst --version`を実行すると、gitのリビジョンも表示するようになりました。
